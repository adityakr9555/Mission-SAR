# Mission SAR

AI-Powered Autonomous Search and Rescue Drone.

## About

Mission SAR is an AI-based system designed to assist search and rescue teams in locating missing people using drone technology.

## Main Features

- Person Detection
- Person Tracking
- Image Segmentation
- GPS Location Tracking
- Autonomous Waypoint Navigation
- Obstacle Avoidance
- Return-to-Home

## Technologies

- Python
- OpenCV
- YOLO
- DeepSORT
- SAM2
- GPS
- Drone Simulation
